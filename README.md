# El Oneblock De Papi [luanti_mineclonia_oneblock]

Un mod para **mineclonia** que crea un mundo vacío (OneBlock) con un nodo de minado infinito. Incluye desarrollo de personaje mediante desafíos y métricas de crecimiento continuo..

## 🚀 Características
- Aun en desarrollo activo
- El Overworld comienza en un bloque
- El Nether comienza en un Bloque
- El End esta en desarrollo.

## 📦 Instalación
1. Descarga o clona este repositorio.
2. Copia la carpeta dentro de tu directorio de mods de Luanti (`~/.luanti/mods/` o `minetest/mods/`).
3. Activa el mod en el menú de configuración del mundo en Luanti.

## 🛠️ Requisitos / Dependencias
- Luanti 5.x o superior
- Mods requeridos: `default` (si aplica)
